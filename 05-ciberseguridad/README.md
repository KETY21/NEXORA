# NEXORA — Ciberseguridad

## Objetivo

Desarrollar conocimientos y buenas prácticas de ciberseguridad aplicables a proyectos digitales y empresas.

## Áreas de aprendizaje

- Seguridad de cuentas
- Protección de datos
- Contraseñas y autenticación
- Phishing e ingeniería social
- Seguridad de dispositivos
- Seguridad de aplicaciones
- Gestión de riesgos
- Privacidad

## Portfolio

Esta sección permitirá documentar progresivamente ejercicios, aprendizajes y proyectos relacionados con ciberseguridad.

## Principio

La seguridad debe formar parte del diseño de cualquier solución digital desde el principio.
