# NEXORA — Gestor de Clientes

## Objetivo

Crear una herramienta sencilla para organizar clientes y oportunidades inmobiliarias.

## Datos del cliente

- Nombre
- Teléfono
- Email
- Nacionalidad
- Tipo de cliente
- Preferencias
- Presupuesto

## Seguimiento

- Fecha de contacto
- Medio de contacto
- Inmueble de interés
- Estado
- Próxima acción
- Observaciones

## Estados

- 🟢 Nuevo
- 🟡 Contactado
- 🔵 En seguimiento
- 🟠 Visita programada
- 🟣 Negociación
- ⚫ Cerrado
- 🔴 No interesado

## Evolución futura

El proyecto podrá incorporar:

- Base de datos
- Panel de control
- Automatización
- Inteligencia artificial
- Gestión de emails
- Estadísticas
- Seguridad y protección de datos
