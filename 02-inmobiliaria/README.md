# NEXORA — Gestión Inmobiliaria

## Objetivo

Desarrollar un sistema organizado para facilitar la gestión de activos inmobiliarios y la atención de clientes nacionales e internacionales.

## Gestión de inmuebles

- Registro de propiedades
- Publicación de inmuebles
- Estado de cada propiedad
- Seguimiento de oportunidades
- Documentación

## Gestión de clientes

- Clientes nacionales
- Clientes internacionales
- Necesidades y preferencias
- Seguimiento comercial
- Historial de contactos

## Comunicaciones

- Control de llamadas
- Gestión de correos electrónicos
- Seguimiento de consultas
- Registro de acciones pendientes

## Objetivo futuro

Crear herramientas digitales que permitan automatizar parte de estos procesos mediante inteligencia artificial.
